# Automotive Batch 02 — 30 Powertrain GLB Parts

**Delivery:** generated conceptual geometry. **NOT OEM CAD or manufacturing validated.**

This release expands the first 76 generated automotive parts to **106** out of the original **317** physical Part entries. Another **211** catalog Parts remain planned. The automotive structure still contains 42 planned assembly nodes separate from the physical-part count.

## Implemented second batch

The committed binary glTF 2.0 file `assets/generated/automotive/fwd-i4-batch-02.glb` contains 30 individually named Part nodes (17 reusable mesh templates, 19,236 template triangles, 1,643,272 bytes). Geometry categories:

- Four-cylinder transverse engine block with visible cylinder layouts and mounting details.
- Crankshaft and pulley, four individual piston assemblies, four connecting rods, piston pins, and ring packs.
- Cylinder head, intake/exhaust camshafts, valve cover, oil pan.
- Timing belt, timing cover and a tensioner.
- Simplified gearbox differential carrier, pinion and side gear assemblies.

This is **real triangle surface geometry**, generated by an authored parametric script, not an empty GLB manifest. Individual generated Part IDs are verified against the catalog and source meshes. Geometry is conceptual: bores, radii, bearing surfaces, valve timings, clearances, oil passages, loads, and materials are not verified against a production automotive assembly.

## Geometry checks

The `npm run assets:validate` command checks both Batch 01 and Batch 02:

- GLB v2 binary magic, byte length, JSON and BIN chunk correctness;
- per-node unique part IDs and catalog binding;
- vertex POSITION and NORMAL bounds/finite values, triangle index ranges and nonzero geometry;
- byte-level committed Git content digest, and geometric regeneration to numerical tolerance;
- no false `cad-reviewed` or manufacturing-validated status claims.

`npm run test` also parses both binaries with Three.js `GLTFLoader` in the headless test suite.

## Constraints are a separate capability

The Batch 02 engine components are **geometry-ready, not yet mechanically detachable**. Their revolute/prismatic/screw connections and real slider-crank kinematics remain to be authored. For actual functional mechanical DAGs on committed geometry, the first implementation covers the four wheel/brake corner assemblies in Batch 01. See [Four-corner mechanical constraints](FOUR-CORNER-CONSTRAINTS.md).
