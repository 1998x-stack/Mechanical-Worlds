# Procedural Conceptual Car Asset Batch 01

Generated by `node tools/asset-pipeline/generate-automotive.mjs` as a real binary glTF 2.0 scene. Distinct node names equal physical catalog Part IDs. Source authored for Mechanical Worlds; geometry is non-brand conceptual demonstration, not reverse-engineered or OEM measurement. No real manufacturing fits, bolt torques, load tests or CAD certification. Units meters, RH +Y up, -Z vehicle forward, +X vehicle right.

Run `npm run assets:build` and `npm run assets:validate`. Regeneration should be byte-stable. Commit only validated GLB changes with matching manifests.

The generator computes the Git blob digest on each regeneration. Regenerated triangulated geometry may vary at float-rounding level across V8 versions; `assets:validate` compares source topology and coordinates within a declared tolerance while verifying the committed output hash exactly.
